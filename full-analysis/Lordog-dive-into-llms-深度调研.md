## 一、项目定位（一句话）

一套由 **上海交通大学《自然语言处理前沿技术》《人工智能安全技术》课程讲义拓展而来的大模型编程实践教程**，公益免费，用可运行 notebook 带读者从微调部署走到对齐与智能体安全。

## 二、项目亮点（3-5 条差异化，开篇呈现）

- 🎓 **高校课程血统**：源自 SJTU 研究生课程讲义，结构严谨、难度梯度合理，非零散博客拼凑。
- 📓 **「课件+教程+脚本」三位一体**：每章配套 PDF 课件、README 教程、可运行 `.ipynb` 脚本，学了就能跑。
- 🧩 **主题前沿且稀缺**：除常规微调/提示外，覆盖 **知识编辑、模型水印、越狱攻击、大模型隐写、GUI Agent、智能体安全、RLHF 对齐** 等小众前沿主题。
- 🇨🇳 **中文母语友好 + 国产化延伸**：联合华为昇腾推出《大模型开发全流程》公益课程（初/中/高级，含 PPT/实验手册/视频）。
- 🆓 **完全免费公益**：明确声明内容来自贡献者经验与科研积累，面向课程设计与学术研究。

## 三、核心架构

课程仓库，非软件系统。结构即「**章节 = 主题模块**」，每章三件套：

```
dive-into-llms/
└── documents/
    ├── chapter1/  dive-into-llm.pdf + README.md + dive-tuning.ipynb   # 微调与部署
    ├── chapter2/  ... + dive-prompting.ipynb                         # 提示学习与思维链
    ├── chapter3/  ... + dive_edit.ipynb                              # 知识编辑
    ├── chapter4/  ... + sft_math.ipynb                              # 数学推理（迷你 R1 蒸馏）
    ├── chapter5/  ... + watermark.ipynb                             # 模型水印
    ├── chapter6/  ... + dive-jailbreak.ipynb                        # 越狱攻击
    ├── chapter7/  ... + llm_stega.ipynb                             # 大模型隐写
    ├── chapter8/  ... + mllms.ipynb                                # 多模态模型
    ├── chapter9/  ... + GUIagent.ipynb                             # GUI 智能体
    ├── chapter10/ ... + agent.ipynb                                # 智能体安全
    └── chapter11/ ... + RLHF.ipynb                                 # RLHF 安全对齐
```

## 四、应用场景与启发

- **系统入门 LLM**：比零散文章成体系，比英文公开课更低门槛，适合自学 + 课程设计双用。
- **找「小众主题」一手资料**：水印/隐写/越狱/对齐这类在安全与生成式 AI 交叉领域的内容，中文优质资料极少，本仓库是稀缺入口。
- **教学复用**：课件（PDF）+ 实验手册（notebook）组合可直接改造成高校/企业内训材料。

## 五、源码解读（核心模块精读）

这不是代码库，真正可执行的「源码」是各章 **notebook**。以第 4 章数学推理为例，其「源码」= `sft_math.ipynb`：从数据构造 → SFT 微调 → 蒸馏一个「迷你 R1」式推理模型，把「让 LLM 学会数学推理」拆成可复现步骤。整套教程的架构价值在于 **「概念 → 课件讲解 → notebook 落地」的闭环设计**，而非某段算法实现。
